## IP 类型才是分水岭：四种“出身”各管一段

WePC 的运营方是澳大利亚 ZGX PTY LTD，2012 年在墨尔本注册，有自己的 ASN（AS151964），IP 资源是自主持有而非转租。这个背景的实际意义在于 IP 段的历史相对可控，不会整段被平台标记过一轮再卖给你。

**原生 IP**：注册地跟机房物理位置一致。日本 IIJ 节点的 IP 在 IP 库里查出来就是日本，新加坡、台湾、英国、德国也是这一类。它是最常见、最不容易出错的类型，做日区、台区、英区的账号运营和电商后台登录都够用。

**家宽 IP**：归属方是真实的家庭宽带运营商。澳洲节点标的是 EXETEL 家宽，这类 IP 在平台风控眼里和普通家庭用户区别不大，是信任度最高的一档。需要提醒的是，同一份第三方资料在表格里写 EXETEL、在实测段落里写 Superloop，两处说法不一致，我没法替你确定当前实际分配的是哪家运营商，下单前可以问客服确认。

**双 ISP**：IP 段同时归属两个 ISP，把机房痕迹盖掉，规避能力比单 ISP 家宽更强。WePC 只在洛杉矶 9929 和 4837 两个套餐上用这种架构，做美区内容基本就是冲它来的。

**CMI 线路 IP**：香港节点走中国移动国际线路，IP 属性是运营商线路，不是住宅。它的长处是国内访问延迟低、带宽稳定，适合建站、跑代理、挂面板，不适合伪装成香港本地家庭用户去养号。这点经常被写乱，买之前想清楚你要的是“像当地人”还是“国内连得快”。

一句话的选法：TikTok 这类对 IP 敏感的业务，优先原生或家宽；建站、代理、远程办公，CMI 更划算，价格也更低。

**需要 Windows 的人。** 默认只有 Linux，没有例外。

**需要频繁换 IP 的营销场景。** 换一次约 18 元，账号矩阵越大越疼。这类需求更适合动态住宅代理池，而不是静态 IP VPS。
